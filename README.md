This is a UI based path planner and motion profile generator made for the VEX Robotics Competition.
Run by installing the required libraries:
numpy 
matplotlib
os
pygame
Then running render.py.

<img width="891" height="767" alt="image" src="https://github.com/user-attachments/assets/63677d47-6724-4dab-bc00-14e42934b0a0" />

You will then be able to draw on a map with splines. When you close the tab the motion profile values will be saved to the paths folder.
